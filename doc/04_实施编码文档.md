# CornerstoneDesigner 实施编码文档

> 前置条件：详细设计文档已审核通过。

## 1. 实施计划

### 阶段一：项目骨架与构建系统（Day 1）

- 创建 CMakeLists.txt，建立工程结构
- 移植 UICornerstone 构建脚本（参照 `build_scripts/build.bat`）
- 创建设计器自身的 JSON 布局原型
- 验证 `cmake -B build` 和 `cmake --build build` 通过

### 阶段二：核心模型与序列化（Day 2-3）

- 实现 ControlModel、SRect、EventBinding 等数据结构
- 实现 Serializer（Layout JSON 导入/导出 + .csd 项目格式）
- 验证：构建 + 运行测试

### 阶段三：业务逻辑层（Day 4-5）

- ProjectManager（项目创建/保存/加载，最近文件）
- EventManager（事件增删查改、命名检查、建议）
- CodeGenerator（header/impl 生成）
- LayoutEngine（排版计算、对齐、Z-Order）
- UndoRedoService（命令模式、历史栈、合并策略）

> 依赖的新控件（TreeView/NumericUpDown/ColorPicker/ComboBox/Splitter）由 UICornerstone 项目独立实现，见 `doc/` 下对应的 `*_需求文档.md`。

### 阶段四：设计器 UI 集成（Day 5-9）

- 用 UICornerstone JSON 布局搭建设计器主界面（含 Splitter 实现三栏布局）
- 集成 TreeView 展示控件层级（ControlModel 树 -> TreeNode 数据）
- 实现画布区域的控件渲染（根据内存模型绘制控件树）
- 实现拖拽放置交互
- 实现属性编辑面板（使用 NumericUpDown、ColorPicker、ComboBox、EditBox、CheckBox）
- 实现事件管理面板
- 实现撤销/重做的 UI 绑定
- 实现内嵌预览

### 阶段五：导出与打磨（Day 10-12）

- 实现完整导出功能
- 集成测试：完整工作流程
- 性能测试：200+ 控件的编辑流畅度
- 兼容性验证：生成的 JSON 在 UICornerstone 测试套件中验证

## 2. 编码规范

### 通用规范

- C++17 标准
- 遵循 UICornerstone 的编码风格
- 所有源代码文件编码：UTF-8 with BOM
- 花括号：Allman 风格

### 命名规则

| 元素 | 规则 | 示例 |
|------|------|------|
| 类 | PascalCase | ControlModel |
| 方法 | pascalCase | toJson |
| 成员变量 | m_camelCase | m_undoStack |
| 参数 | camelCase | controlId |
| 常量 | kCamelCase | kSnapThreshold |
| 宏 | UPPER_SNAKE | DESIGNER_MAX_UNDO |

### 文件头

```cpp
// <filename>
// CornerstoneDesigner
//
// <description>
```

## 3. 依赖项

| 依赖 | 来源 | 用途 |
|------|------|------|
| UICornerstone | git submodule | UI 框架 + JSON 布局 + SDL3 渲染 |
| nlohmann/json | UICornerstone submodule | JSON 解析与序列化 |
| SDL3/SDL3_ttf/SDL3_image | UICornerstone submodule | 窗口、渲染、字体、图片 |

UICornerstone 作为 git submodule 引入（`subModules/UICornerstone`）。

### CMakeLists.txt 结构概要

```cmake
cmake_minimum_required(VERSION 3.16)
project(CornerstoneDesigner C CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 引入 UICornerstone
add_subdirectory(subModules/UICornerstone)

# 设计器源码
add_executable(CornerstoneDesigner
    src/main.cpp
    src/App.cpp
    src/ControlModel.cpp
    src/Serializer.cpp
    src/ProjectManager.cpp
    src/EventManager.cpp
    src/CodeGenerator.cpp
    src/LayoutEngine.cpp
    src/UndoRedoService.cpp
)

target_include_directories(CornerstoneDesigner PRIVATE include)
target_link_libraries(CornerstoneDesigner PRIVATE UICornerstone)
```

## 4. 构建与验证

```bash
# 克隆（含子模块）
git clone --recursive git@github.com:SeaOceanLiu/CornerstoneDesigner.git

# 构建（参照 UICornerstone 构建方式）
build_scripts\\build.bat sdl3

# 运行
build\\sdl3\\Debug\\CornerstoneDesigner.exe
```

### 提交前验证

按顺序执行：

1. `cmake --build build --config Debug`
2. 运行测试验证核心逻辑
3. 验证代码格式

- 提交信息格式：`阶段X: 简短描述`
- 不提交 `bin/`、`obj/`、`.vs/`、`build/`
