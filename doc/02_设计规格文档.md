## 2. 系统架构概述

CornerstoneDesigner 本身是一个 UICornerstone 应用，采用声明式 UI（JSON 布局）为主、命令式代码为辅的混合架构。

```
┌─────────────────────────────────────────────────────────────┐
│                    CornerstoneDesigner                        │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                  UICornerstone 控件树                    │  │
│  │  ┌──────────┐  ┌───────────┐  ┌──────────────────┐  │  │
│  │  │ Toolbox  │  │  Canvas   │  │  PropertyPanel   │  │  │
│  │  │ (Panel)  │  │  (Panel)  │  │  (Panel/Scroll)  │  │  │
│  │  └──────────┘  └───────────┘  └──────────────────┘  │  │
│  │  ┌──────────┐  ┌───────────┐  ┌──────────────────┐  │  │
│  │  │ TreeView │  │ MenuBar   │  │  StatusBar      │  │  │
│  │  └──────────┘  └───────────┘  └──────────────────┘  │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                    Core 引擎层                          │  │
│  │  LayoutEngine │ ProjectManager │ Serializer │ CodeGen │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### 设计原则

- **Dogfooding**：设计器自身的 UI 使用 UICornerstone JSON 声明式布局构建
- **事件驱动**：用户交互通过 UICornerstone 事件系统处理
- **内存模型**：设计器维护一个独立于渲染的控件内存树，与显示的 UICornerstone 控件树保持同步
- **JSON 核心**：所有数据以 JSON 为交换格式，设计器内部也使用 JSON 作为项目文件格式

## 3. 模块分解

### M1 项目模块 (ProjectManager)

| 职责 | 说明 |
|------|------|
| 项目生命周期 | 创建、打开、保存、关闭 .csd 项目 |
| 文件格式 | .csd (JSON 格式，含布局 + 元数据 + 资源引用) |
| 最近文件 | 记录最近 10 个文件路径 |
| 自动保存 | 定时自动备份 |

### M2 控件内存模型 (ControlModel)

| 职责 | 说明 |
|------|------|
| 控件属性映射 | 维护内存中的控件属性表，与 UICornerstone 控件类型对齐 |
| 类型注册 | 注册所有支持控件类型及其默认属性 |
| 序列化 | ToJson / FromJson 相互转换 |

### M3 布局引擎 (LayoutEngine)

| 职责 | 说明 |
|------|------|
| 排版计算 | 将用户拖拽转换为控件 rect 坐标 |
| 对齐系统 | 吸附对齐参考线、等距分布（阈值 8px） |
| Z-Order | 置前/置后/上移/下移 |
| 缩放 | 画布坐标系与控件坐标系转换 |
| 约束检测 | 子控件不得超出父容器边界 |

### M4 属性编辑器

| 职责 | 说明 |
|------|------|
| 动态表单 | 根据选中控件类型生成对应的属性编辑 UI |
| 值验证 | 数值范围、颜色格式、必填字段校验 |
| 批量编辑 | 多选时仅显示共有属性 |
| 重置 | 恢复属性为 UICornerstone 默认值 |

### M5 事件管理器 (EventManager)

| 职责 | 说明 |
|------|------|
| 事件绑定 | 为控件实例绑定事件 |
| 函数命名检查 | 检测命名冲突和无效标识符 |
| 导出 | 生成事件函数签名列表 |
| 骨架生成 | 输出 .h 声明和 .c 骨架实现 |

### M6 代码生成器 (CodeGen)

| 职责 | 说明 |
|------|------|
| JSON 导出 | 将控件树序列化为 LayoutParser 兼容的 JSON 格式 |
| C/C++ 骨架生成 | 生成 `void handler(UIControlHandle ctl, void* user)` 函数定义 |
| 项目报告 | 导出控件清单与事件清单 |

### M7 撤销/重做 (UndoRedo)

| 职责 | 说明 |
|------|------|
| 命令模式 | 每个操作封装为可撤销的命令对象 |
| 历史栈 | 至少 50 步 |
| 合并策略 | 连续同类操作（如移动）自动合并 |

### M8 预览引擎

预览不需要外部进程。由于设计器本身就是 UICornerstone 应用，可以直接将正在编辑的布局 JSON 通过 `LoadLayout` 加载到预览区域中进行内嵌渲染。

```
用户拖动控件 ──> 更新内存模型 ──> SerializeToJson()
                                      │
                                      ▼
                              LoadLayout(json)
                                      │
                                      ▼
                           UICornerstone 渲染
                           （当前预览区域）
```

## 5. 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| UI 框架 | UICornerstone SDL3 | dogfooding，同时验证框架自身能力 |
| JSON 库 | nlohmann/json | UICornerstone 已依赖，复用 |
| 架构模式 | 事件驱动 + 内存模型同步 | 解耦渲染与数据，易于测试 |
| 撤销/重做 | 命令模式 | 内存可控，支持合并 |
| 预览方式 | 内嵌 LoadLayout | 设计器本身就是 UICornerstone 应用，天然支持 |

## 6. 文件格式

### .csd 项目文件

```json
{
  "version": "1.0",
  "layout": { /* 控件树 JSON */ },
  "events": [
    { "controlId": "btn1", "eventType": "onClick", "handlerName": "onBtn1_Click" }
  ],
  "resources": {
    "fonts": ["HarmonyOS_Sans_SC.ttf"],
    "images": ["button_bg.png"]
  },
  "metadata": {
    "viewport": { "w": 1200, "h": 800 },
    "dpiScale": 1.0,
    "createdAt": "2026-06-23T10:00:00Z"
  }
}
```

### JSON 导出格式

严格遵循 UICornerstone `LayoutParser` 输入格式（参照 UICornerstone 仓库 `layouts/` 目录下的示例文件）。

## 7. 控件类型注册表

| 控件类型 | 核心属性 | 特有属性 |
|---------|---------|---------|
| Panel | rect, children, visible | layout |
| Label | rect, caption, font.size | textAlign |
| Button | rect, caption, colors.background | actor, luotiAni, onClick |
| CheckBox | rect, caption, checked | threeState |
| EditBox | rect, text, placeholder | password, maxLength, events |
| TextArea | rect, text | readOnly, scrollable |
| ProgressBar | rect, value | showPercentage |
| ScrollBar | rect, orientation | min, max, value |
| Menu | rect, items | orientation |
| WinFrame | rect, caption, children | resizable |
