## 1. 控件内存模型（ControlModel）

### 1.1 属性系统

设计器维护一套独立于 UICornerstone 渲染的控件属性内存模型。每次用户操作修改内存模型，然后通过序列化同步到 UI 渲染。

核心数据结构：

```cpp
// include/Designer/ControlModel.h

struct SRect {
    float x, y, w, h;
};

struct Margin {
    float left, top, right, bottom;
};

struct FontConfig {
    int size = 14;
    std::string family;
};

struct ColorValue {
    std::string normal;
    std::string hover;
    std::string pressed;
    std::string disabled;
};

struct ControlProperties {
    std::string type;          // Panel, Label, Button, ...
    std::string id;
    std::string caption;
    SRect rect;
    FontConfig font;
    ColorValue colors;
    Margin margin;
    bool visible = true;
    bool enable = true;
    float scaleX = 1.0f;
    float scaleY = 1.0f;
    nlohmann::json extended;   // 各控件特有属性
};
```

### 1.2 控件树

```cpp
class ControlModel {
public:
    std::string id;
    ControlProperties props;
    std::vector<std::unique_ptr<ControlModel>> children;
    ControlModel* parent = nullptr;
    int zIndex = 0;

    // 事件绑定
    std::vector<EventBinding> events;

    // 序列化
    nlohmann::json toJson() const;
    static std::unique_ptr<ControlModel> fromJson(const nlohmann::json& j);
};
```

### 1.3 序列化规则

| 规则 | 说明 |
|------|------|
| 空值省略 | 默认值属性不写入 JSON |
| 空子控件 | children 数组为空时省略字段 |
| 颜色格式 | 始终输出 6 位十六进制 #RRGGBB |
| 数值精度 | 坐标和尺寸保留 1 位小数 |
| 坐标顺序 | JSON 输出 x,y,w,h，对应 UICornerstone SRect |

### 1.4 JSON 输出示例

```json
{
  "controls": [{
    "type": "Panel",
```

## 2. 事件管理器（EventManager）

### 2.1 数据结构

```cpp
struct EventBinding {
    std::string controlId;
    std::string eventType;    // onClick, onMouseEnter, ...
    std::string handlerName;
};
```

### 2.2 接口

```cpp
class EventManager {
public:
    bool addEvent(const std::string& controlId,
                  const std::string& eventType,
                  const std::string& handlerName);
    bool removeEvent(const std::string& controlId,
                     const std::string& eventType);
    std::vector<EventBinding> getEvents(const std::string& controlId) const;
    bool isHandlerNameUnique(const std::string& name) const;
    std::string suggestHandlerName(const std::string& baseName) const;
    std::vector<EventBinding> exportAllEvents(const ControlModel* root) const;
    bool isValidIdentifier(const std::string& name) const;
};
```

### 2.3 支持的 UICornerstone 事件类型

| 事件类型 | 触发器 |
|---------|--------|
| onClick | 鼠标点击 |
| onMouseEnter | 鼠标进入控件区域 |
| onMouseLeave | 鼠标离开控件区域 |
| onValueChanged | 值改变（EditBox/CheckBox） |
| onFocus | 获得焦点 |
| onBlur | 失去焦点 |

所有事件回调签名一致：`void handler(UIControlHandle ctl, void* user)`

JSON 中表达形式：`"events": { "onClick": "handlerName" }`

## 3. 代码生成器（CodeGenerator）

### 3.1 输出文件

```
output/
  layout.json      - UICornerstone 布局文件（LayoutParser 格式）
  events.h         - 事件函数声明（C 头文件）
  events.c         - 事件函数骨架实现
  event_list.json  - 事件列表（机器可读格式）
```

## 4. 布局引擎（LayoutEngine）

### 4.1 接口

```cpp
class LayoutEngine {
public:
    // 计算放置位置
    SRect calculatePlacement(const SPoint& canvasPos, const std::string& controlType);

    // 边界约束
    bool isWithinBounds(const ControlModel* child, const ControlModel* parent) const;

    // 对齐吸附（阈值 8px）
    SPoint snapToGuides(const SPoint& pos,
                        const std::vector<ControlModel*>& siblings) const;

    // 均匀分布
    void distributeEvenly(std::vector<ControlModel*>& controls, bool horizontal);

    // Z-Order 操作
    void bringToFront(ControlModel* control);
    void sendToBack(ControlModel* control);
    void moveUp(ControlModel* control);
    void moveDown(ControlModel* control);
};
```

### 4.2 对齐系统

对齐阈值：8px。参考线类型：

- 父容器左/中/右/上/中/下边线
- 同级控件的左/右/上/下边线和中线
- 同级控件等间距参考

```cpp
class UndoRedoService {
```

合并策略：

| 操作类型 | 合并条件 | 方式 |
|---------|---------|------|

## 7. 预览机制

设计器本身就是 UICornerstone 应用，预览采用内嵌方式：

```
用户编辑控件树
    │
    ▼
ProjectManager::exportLayout("temp.json")
    │
    ▼
Serializer 序列化为 LayoutParser 格式
    │
    ▼
UICornerstone_LoadLayout(json_string)
    │
    ▼
UICornerstone 控件树渲染到预览区域
```

预览区域是设计器主界面的一个 Panel 控件，通过切换布局内容实现预览。

## 10. 错误处理策略

| 场景 | 处理方式 |
|------|---------|
| JSON 解析失败 | 显示错误位置和期望 token |
| 文件读写失败 | 返回错误码 + 错误消息字符串 |
| 控件 ID 重复 | 自动追加编号后缀 |
| 无效事件函数名 | 实时 UI 提示并阻止导出 |
| 预览加载失败 | 显示错误信息到状态栏 |
