## 1. 项目背景

UICornerstone 是一个基于 C++17 的多后端跨平台 UI 控件库（SDL3/SFML/Raylib），提供声明式 UI 定义方式——通过 JSON 描述控件树和事件绑定，`LayoutParser` 自动解析。目前已提供 12+ 控件（Label、Button、CheckBox、EditBox、TextArea、ProgressBar、ScrollBar、Menu、WinFrame、Panel 等）。

当前 UICornerstone 的 UI 布局完全依赖手写 JSON 或手写 C ABI 代码，缺少可视化设计工具，导致：
- 布局调试周期长（修改 JSON → 编译 → 运行 → 查看效果）
- 非技术人员无法参与 UI 设计
- 控件属性调整效率低

CornerstoneDesigner 旨在填补这一空白，构建一个 **基于 UICornerstone 自身的可视化 UI 设计器**（dogfooding），输出 UICornerstone 可直接消费的声明式 UI JSON 和事件响应函数代码。

## 2. 项目目标

构建一个 C++17 桌面应用程序，基于 UICornerstone（SDL3 后端）实现自我承载，允许用户通过拖拽式可视化界面设计 UICornerstone UI 布局，并生成：

1. **声明式 UI JSON 文件**：符合 UICornerstone `LayoutParser` 格式规范的控件树描述
2. **事件响应函数列表**：用户绑定在控件上的事件对应的 C/C++ 函数签名和骨架代码

## 3. 目标用户

| 用户类型 | 特征 | 核心诉求 |
|---------|------|---------|
| UICornerstone 应用开发者 | C++ 开发者，熟悉 JSON 布局 | 加速 UI 开发，减少手写 JSON 错误 |
| UI 设计师 | 非程序员，使用过 Figma/Sketch | 可视化编辑界面，导出给开发使用 |
| 技术评估者 | 架构师、技术负责人 | 快速搭建 UI 原型验证可行性 |

## 5. 非功能需求

| 编号 | 需求 | 指标 |
|------|------|------|
| N1 | 启动时间 | <= 3 秒 |
| N2 | 画布操作帧率 | 拖拽/缩放 >= 30 FPS |

| N4 | JSON 导出正确性 | 生成的 JSON 能被 UICornerstone `LoadLayout` 正确解析（以 `test_layout` 和 `test_layout_advanced` 为验证基准） |

## 6. 技术约束

- 使用 C++17 和 UICornerstone 自身构建 UI
- 使用 CMake 3.16+ 构建系统
- 使用 Visual Studio 2022 开发（Windows 10+）
- 设计器本身用于设计 UICornerstone 布局，实现 dogfooding
- 预览功能直接调用 `UICornerstone_LoadLayout` 在编辑器中内嵌实时渲染

## 7. 边界

- 本工具仅生成声明式 UI JSON 和事件函数骨架，不编译或链接 UICornerstone 应用
- 不实现 UICornerstone 高级动画/粒子特效的内容级可视化编辑（LuotiAni 时间轴/关键帧等）
- **动画控件基础托管**（F 需求补充）：支持在画布放置 `animation` 控件（LuotiAni）、编辑其 rect 与**动画资源路径**（`luotiAni` 字段，`.jsonc` 路径字符串，仅托管不解析/不编辑动画内容），预览中由 UICornerstone 正常播放
- **资源面板**（F 需求补充）：v1.0.0 无 ResourceLoader 控件，资源机制为布局顶层 `resourceProviders` 挂载（`name`/`path`）；设计器提供布局级资源面板，增删改挂载点，资源引用（`provider:<id>` 前缀）可填入图片/字体/动画等资源属性
- **组件系统**（P2 需求补充）：用户可将多个控件拼装为组件（自定义控件）并在各处引用；v1.0.0 引擎级支持（顶层 `components`：`props` + `template` + `{{ }}` 占位符 + `_comp_` 事件，引用即 `type=组件名`）；设计器提供组件编辑器（模板编辑 + props 声明）与工具箱"组件"动态分组

## 8. 术语表

| 术语 | 说明 |
|------|------|
| LayoutParser | UICornerstone 中的 JSON 布局解析器 |
| C ABI | UICornerstone 提供的纯 C 兼容 API（UICornerstone_* 函数） |
| 声明式 UI | 通过 JSON 描述控件树和属性的 UI 定义方式 |
| .csd 项目文件 | CornerstoneDesigner 的原生项目格式，包含布局 + 元数据 |
| dogfooding | 使用 UICornerstone 自身来构建它的设计器工具 |
