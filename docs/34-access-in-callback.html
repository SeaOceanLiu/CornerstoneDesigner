34 在事件回调中访问其他控件

C++ Binding

回调的第一个参数通常是事件源；也可以按 ID 再查找其他控件：

nameEdit.SetCallback(PropertyNames::kEventTextChanged, [ui = ui.get()](const Event& e) {
    const std::string text = e.GetTextChanged();
    auto status = ui->FindControl("statusLabel");
    if (status.IsValid()) status.SetString(PropertyNames::kCaption, "你好，" + text);
});

回调在 ProcessEvents 期间执行，应在 UI 线程运行。不要在回调里做长时间阻塞操作；重活可以记录状态，延到下一帧处理。

LoadLayout 重建控件树后，之前缓存的 Control 代理或裸句柄可能失效。重建后重新 FindControl，并在使用前检查 IsValid()。

C ABI 回调中访问其他控件

typedef struct {
    UIInstance inst;
} TextState;

static void on_name_changed(UIControlHandle ctl, const UIEventData* ev, void* user) {
    (void)ctl;
    TextState* app = (TextState*)user;
    UIControlHandle status = UICornerstone_FindControl(app->inst, "statusLabel");
    if (!status) return;

    char msg[512];
    snprintf(msg, sizeof(msg), "你好，%s", ev->data.strVal ? ev->data.strVal : "");
    UICornerstone_SetString(app->inst, status, "caption", msg);
}

UIControlHandle nameEdit = UICornerstone_FindControl(inst, "nameEdit");
TextState app = { inst };
UICornerstone_SetCallback(inst, nameEdit, "text-changed", on_name_changed, &app);

C ABI 回调同样在 ProcessEvents 中执行；耗时工作应延后，不要阻塞事件泵。
