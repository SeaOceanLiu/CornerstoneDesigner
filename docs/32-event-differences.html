38 JSON 动作与绑定控件事件的区别

方式适合注册时机回调数据
RegisterAction("onSave", ...)布局 JSON 中的 events 动作LoadLayout 之前只拿 Control
SetCallback("click", ...)代码直接控制某个控件控件找到后，任意时刻可读取 Event 负载

设计器导出的 C++ 工程使用 RegisterAction 把事件名映射到 events.c 中的函数：

ui->RegisterAction("onSaveClick", [](Control c) {
    onSaveClick(c.Handle(), nullptr);
});

如果需要在代码中读取文本、行号、颜色等事件负载，请对控件使用 SetCallback；如果只是响应设计器事件面板里填写的 handler，使用 RegisterAction。
