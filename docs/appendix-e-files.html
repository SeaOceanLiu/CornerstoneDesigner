附录 E 文件格式

E.1 .csd 工程

{
  "app": "CornerstoneDesigner",
  "version": 1,
  "layout": {
    "controls": [ ... ],
    "components": { ... },
    "viewport": { "id": "canvas", "width": 1280, "height": 800, "background": "#FFFFFFFF" },
    "theme": { ... }
  },
  "metadata": {
    "canvas": { ... },
    "handlers": { "onClick": "..." },
    "handlerIncludes": "#include <stdio.h>"
  }
}
字段说明
app固定为 CornerstoneDesigner
version工程格式版本
layout.controls控件树（含 id/type/rect/属性/events）
layout.components组件定义与模板
layout.viewport画布尺寸、ID、背景
layout.theme项目主题（可选）
metadata设计器专用：事件代码、包含文件、画布元数据

E.2 导出 JSON

导出 JSON 是 UICornerstone 运行布局，不包含设计器 metadata。常含 controls、viewport、theme、components、resourceProviders。

E.3 C 工程

导出目录/
  main.c
  layout.json
  events.h
  events.c
  event_list.json
  CMakeLists.txt
  README.md
  assets/           # 构建后拷贝的运行资源

导出目录/

  CMakeLists.txt
  README.md

  assets/

E.5 设计器设置

designer_settings.json（exe 同目录）：

{
  "lastFileDir": "D:/Projects",
  "lastFolderDir": "D:/Exports",
  "recentFiles": ["D:/Projects/Demo.csd"]
}

E.6 设计器 UI 主题

designer_theme.json（exe 同目录）：主题对象，结构同项目主题，但不属于任何工程。源码位置为 layouts/designer_theme.json，构建时复制到输出目录。

E.7 资源提供者

布局中通常以如下形式出现：

"resourceProviders": {
  "demo": "D:/Projects/Demo/assets"
}

控件引用 provider:demo/icon.png。设计器资源面板负责维护名称与目录映射。

E.8 编码与换行

  • 源代码 .h/.cpp：UTF-8 with BOM。
  • JSON/HTML/CMake/README：UTF-8。
  • 导出源代码带 BOM；JSON 与构建文件不带 BOM。
