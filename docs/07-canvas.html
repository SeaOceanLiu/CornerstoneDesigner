8 画布编辑

画布是设计器的主工作区。所有位置、大小、层级和对齐操作都在这里完成。

图 8-1 画布中选中控件后的状态

8.1 选择控件

操作结果
单击控件选中该控件，显示蓝色选中框和八个控制点
Ctrl + 单击加入/移出当前选择集；多选时次级控件显示橙色框
在空白处拖拽框选与矩形相交的根级控件
Ctrl + 空白拖拽并入式框选，保留已有选择
在容器内容区拖拽只框选该容器的子控件
单击容器内容区选中容器本身（不启动子控件框选）

框选移动距离小于阈值时按空白单击处理，用于清空选择。TabControl 的页签点击会切换到该页；隐藏页不参与命中。

8.2 移动控件

  • 按住控件本体拖动；选中多个时整体移动。
  • 启用“控件吸附”后，控件边缘和中心会吸附到其他控件；橙色参考线显示对齐位置。
  • 启用“网格吸附”后，位置吸附到当前网格间距。

8.3 调整大小

选中控件后拖动八个控制点：

  • 四角：同时改变宽高。
  • 四边：只改变一个方向。
  • 拖动时按网格/控件吸附规则微调。

尺寸不能为负；极小的拖动会保持原尺寸。Tab 页 Panel 等特殊容器不允许直接缩放，需通过父 TabControl 调整。

8.4 缩放与平移画布

  • 工具栏缩放下拉：25%、50%、75%、100%、150%、200%。
  • − / +：按档位缩放；100%：恢复 1:1。
  • 鼠标滚轮：连续缩放。
  • 中键拖动或空格 + 拖动：平移。
  • 纸面超出视口时，底部/右侧滚动条出现。

缩放只影响设计器显示，不改变控件坐标和导出布局。

8.5 网格与吸附

选项作用
网格显示纸面网格
网格单元格网格间距，10/20/25/40/50/100/200
网格吸附拖动/缩放时对齐网格
控件吸附对齐其他控件的左/中/右、上/中/下

参考线颜色为橙色，只在拖动期间显示，不写入工程。

8.6 对齐与分布

选中至少两个控件后，画布工具栏的“对齐”下拉可用。命令立即执行，并作为一个独立撤销步：

命令结果
左对齐 / 水平居中 / 右对齐按选择集包围盒对齐 X 方向
顶对齐 / 垂直居中 / 底对齐按选择集包围盒对齐 Y 方向
等宽 / 等高以主选控件（最后选中）的宽/高为基准
水平分布 / 垂直分布按左/上缘排序，首末不动，中间等间距

8.7 状态预览

工具栏“状态”下拉用于设计期查看控件的不同状态：

  • 跟随：按当前鼠标交互状态显示。
  • 常态 / 悬停 / 按下 / 禁用：强制选中控件显示为该状态。

状态预览只影响设计器显示，不写入属性、不进入导出。切换选中或进入预览模式会自动恢复。

8.8 画布尺寸

工具栏画布尺寸下拉提供 1024×768、1280×800、1440×900、1920×1080 和“自定义…”。选择“自定义…”打开宽高输入对话框。画布尺寸是最终运行窗口的基准尺寸；改变后网格、状态栏和报告截图尺寸同步更新。

8.9 层级与顺序

控件树中越靠下的同级节点越靠前绘制。调整层级使用控件树的右键菜单：

  • 上移 / 下移：在同级内前后移动。
  • 移到画布根：把控件从当前父容器移到根级。
当前版本“编辑”菜单中的复制、粘贴、置前、置后是预留入口，尚未实现；请用控件树右键的上移/下移/移到根来调整层级。详见 附录 G。

8.10 删除与撤销

  • Delete 或编辑 → 删除：删除选中控件及其子树。
  • Ctrl+Z：撤销。
  • Ctrl+Y：重做。

删除、放置、移动、缩放、属性修改和组件操作都会进入撤销栈；预览/设计模式切换通常不进入撤销栈。
