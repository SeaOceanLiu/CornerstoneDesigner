13 资源管理

资源面板用于管理项目依赖的图片、字体、动画等资源。资源通过“名称 → 目录”的提供者映射，布局中使用相对资源路径，避免把绝对路径写死。

13.1 打开资源面板

左侧工具箱切换到“资源”页签。面板上方是资源提供者列表，下方是“插入”“修改”“删除”操作按钮。

列表通常显示两列：

  • 名称：布局和属性中引用资源时使用的提供者名，例如 ui。
  • 路径：该提供者对应的磁盘目录。

13.2 插入资源提供者

  1. 点击“插入”。
  2. 在名称输入框中输入唯一名称，例如 demo。
  3. 点击“选择目录…”或“选择文件…”选择资源所在位置。
  4. 确认后，提供者出现在列表中。
  5. 在控件属性中使用 provider:demo/xxx.png 这样的路径引用资源。
名称必须在工程内唯一。重复名称会导致资源查找不确定；设计器会拒绝或提示。

13.3 修改与删除

操作说明
修改选中列表行后点击，修改名称或路径
删除移除提供者；已引用该资源的控件可能显示缺失

删除前请确认没有布局或组件仍在引用该提供者。资源提供者不会把文件复制到工程里，只保存路径。

13.4 路径规则

  • 资源路径应尽量使用相对路径，避免绝对路径。
  • provider:名称/相对路径 指向提供者目录下的文件。
  • 图片、字体、动画 JSONC 等资源的相对路径解析规则由 UICornerstone 运行时统一处理。
  • 导出工程时，设计器会把需要的资源与路径写入导出包；请以导出结果为准检查。

13.5 图片和字体

  • Image 控件通过图片属性选择资源；属性面板通常提供资源选择或文本输入。
  • 字体通过字体名称或字体资源属性设置。
  • 资源缺失时，控件可能显示为空、占位图形或回退字体。

13.6 动画资源

Animation 控件使用 LuotiAni JSONC 文件。把动画目录加入资源提供者后，在动画路径属性中填写 provider:名称/动画.jsonc。预览和导出会按运行时资源规则加载。

13.7 资源排查

  1. 确认提供者名称和布局引用完全一致（区分大小写）。
  2. 确认提供者目录中确实存在该文件。
  3. 确认路径分隔符和相对路径正确。
  4. 在预览中查看；设计画布可能不加载全部资源。
  5. 如果只在导出工程中失败，检查导出目录中的资源分布。
