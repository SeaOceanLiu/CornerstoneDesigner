22 第一次使用主题：给按钮换色

下面按顺序做一遍。完成后你会得到：基主题、类、按钮规则、悬停规则，并能在预览中看到效果。

  1. 新建工程，从工具箱放置一个 Button，文本改成“保存”。
  2. 选中按钮，点击右侧“事件”旁边的“属性”，确认没有手动改过它的背景色。显式属性会覆盖主题。
  3. 打开 编辑 → 主题…。
  4. 在“作用域”保持“基主题”。
  5. 在“选择器”输入或从下拉选择 button.primary。
  6. “背景色”填 #2D7FF9FF，“文字色”填 #FFFFFFFF。
  7. “边框色”填 #4A90D9FF，“文字阴影”填 #00000066。
  8. “字体”下拉选择 harmonyos-sans-sc-regular；“字号”填 16；“圆角”填 8。
  9. “内边距(上/右/下/左)”填 8、16、8、16。
  10. “box-shadow”填下面这个 JSON 对象：
    {"color":"#00000066","offset-x":0,"offset-y":6,"blur":16,"spread":0}
  11. 点击“新增规则”。下方规则列表出现 button.primary，声明数为 9。
  12. 保持按钮在画布中被选中，回到主题管理器，点击“类应用到选中”。按钮会获得 primary 类。
  13. 再新增一条规则：选择器 button.primary:hover，背景色改成更亮的 #4A90D9FF，点击“新增规则”。
  14. 点击“应用”关闭管理器，按 F5 打开预览，把鼠标移到按钮上。

此时你应该看到：按钮常态是蓝色，悬停变亮。回到画布后，按钮本身的位置、大小、文本都不变，只是外观来自主题。

修改已有规则时不要点“新增规则”。先在上方规则列表选中该规则，修改字段，然后点“应用”（或切换到别的规则/作用域让修改保存）。“新增规则”会创建一条新规则，容易产生重复。
