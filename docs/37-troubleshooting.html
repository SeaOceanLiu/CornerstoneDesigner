37 故障排查与 FAQ

遇到问题时按“现象 → 可能原因 → 处理”排查。设计器会在控制台输出日志；开发构建下终端窗口中的日志是首要线索。

37.1 程序无法启动

现象可能原因处理
缺 DLL / 0xc000007b运行依赖未与 exe 同目录确认 UICornerstone、UIBackend_sdl3、SDL3 运行库与 assets 已拷贝
窗口黑屏/无内容后端或资源初始化失败查看控制台错误；确认使用 SDL3 构建
启动后立即退出主布局 main_layout.json 缺失或非法确认 exe 同目录有 main_layout.json；恢复默认布局

37.2 布局加载失败

  • JSON 语法错误：用原始 JSON 或外部编辑器检查括号、逗号、引号。
  • 控件类型不存在：确认 UICornerstone 版本与设计器匹配。
  • 资源路径错误：通常不会阻止 LoadLayout，但资源显示为空。
  • 工程版本不兼容：尝试从备份恢复，或在新版本中重新导入 JSON。

37.3 画布点不中 / 拖不动

  1. 检查预览窗口是否在最前并抢走焦点；关闭/切回主窗口。
  2. 检查是否处于预览模式或组件编辑模式；退出后再操作。
  3. 检查控件是否在隐藏 Tab 页或 visible=false 的容器内。
  4. 检查控件是否被其他控件完全覆盖；从控件树选中。
  5. 检查是否有模态对话框打开；先关闭对话框。

37.4 字体或图片不显示

  • 确认资源提供者名称和路径正确。
  • 确认资源文件存在且扩展名正确。
  • 在预览中查看；设计画布可能不加载全部资源。
  • 字体名称必须是 UICornerstone 支持的字体枚举名或已加载资源。
  • 检查导出目录中是否包含资源和 provider 映射。

37.5 事件不生效

  1. 确认事件面板中确实有绑定，handler 名称合法且无冲突。
  2. 确认预览/导出工程中的控件 ID 与绑定一致。
  3. 确认事件类型是控件实际支持的事件（见附录 C）。
  4. 导出后检查 events.c 是否实现了函数体，而不是空骨架。
  5. 查看运行时控制台是否有未注册动作/回调错误。

37.6 主题不生效

  • 设计画布主要显示显式样式；请在预览/导出中查看主题。
  • 确认控件已分配类，选择器拼写正确。
  • 确认控件没有显式设置同名属性（显式优先）。
  • 确认规则在正确作用域：基主题、变体、媒体、容器。
  • 确认媒体/容器条件命中。
  • 用“主题 JSON…”检查结构。

37.7 设计器主题不生效

  • 确认修改的是 exe 同目录的 designer_theme.json，不是源码目录里的文件。
  • 修改后选择 视图 → 重新加载设计器主题。
  • 查看控制台 [Theme] 日志：文件缺失、JSON 非法或 ApplyTheme 失败都会打印。
  • 设计器主题只影响设计器 UI，不影响项目画布/预览。

37.8 最近文件/路径问题

  • 最近文件失效：打开时会自动移除；检查文件是否被移动/删除。
  • 超长路径：设计器内部使用长路径兼容处理；仍建议避免过深目录。
  • 文件对话框打不开：确认系统对话框可用，目标目录存在。

37.9 导出失败

  • 事件命名冲突或非法：先修正事件面板。
  • 目标目录不可写：换一个空目录。
  • 组件编辑中：先返回画布再导出。
  • 资源缺失：导出仍可能成功，但运行会缺资源。

37.10 如何提供有效反馈

报告问题时请附：

  • 复现步骤（从新建/打开哪个工程开始）。
  • 设计器控制台日志（尤其是错误和最后几行）。
  • 能复现的最小 .csd 或布局 JSON。
  • 截图（画布、属性/事件面板、错误提示）。
  • 设计器与 UICornerstone 的版本/构建时间。
