28 在程序代码中找到控件

C++ Binding

#include "UICornerstone.h"
#include "Control.h"
#include "PropertyNames.h"
#include <cstdio>

// 假设 ui 已创建并加载了 layout.json
Control saveBtn = ui->FindControl("saveBtn");
if (!saveBtn.IsValid()) {
    std::fprintf(stderr, "找不到控件 saveBtn\n");
    return;
}

FindControl 返回 Control 代理。代理可拷贝，拷贝共享同一个控件状态；控件销毁后 IsValid() 会变为 false。

28.1 默认 ui / inst 已创建并加载布局，只聚焦“按 ID 查找”。完整 C++/C ABI 示例见 35。

C ABI

#include "UICornerstoneAPI.h"
#include <stdio.h>

UIControlHandle saveBtn = UICornerstone_FindControl(inst, "saveBtn");
if (!saveBtn) {
    fprintf(stderr, "找不到控件 saveBtn\n");
    return;
}
