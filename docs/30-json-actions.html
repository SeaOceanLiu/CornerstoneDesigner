36 事件回调方式 1：注册 JSON 动作

如果事件名写在布局 JSON 的 events 中，例如 {"onClick":"onSave"}，宿主用 RegisterAction("onSave", ...) 注册同名动作。注册必须发生在 LoadLayout 之前。

C++ Binding

// 假设 ui 已创建
ui->RegisterAction("onSave", [](Control ctl) {
    std::printf("action=%s\n", ctl.GetId().c_str());
});
ui->LoadLayoutFromFile("layout.json");

C ABI

typedef struct { UIInstance inst; int saved; } AppState;

static void on_save_action(UIControlHandle ctl, void* user) {
    AppState* app = (AppState*)user;
    app->saved = 1;
    printf("action control id=%s\n",
           UICornerstone_GetControlId(app->inst, ctl));
}

AppState app = { inst, 0 };
UICornerstone_RegisterAction(inst, "onSaveClick", on_save_action, &app);
UICornerstone_LoadLayoutFromFile(inst, "layout.json");
注册时机：RegisterAction 先把“动作名 → 回调”登记到动作表；LoadLayout 解析控件的 events 时才按名字查表并绑定。若加载后才注册，解析器已经跳过该事件，之后注册不会回溯绑定已创建的控件。需要后绑定请使用 31 的 SetCallback，或重新加载布局。
