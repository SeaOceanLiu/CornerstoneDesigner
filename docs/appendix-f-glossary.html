附录 F 术语表

术语说明
BenchUICornerstone 的根容器/画布，对应设计器中的画布。属性面板未选中控件时显示 Bench 属性。
控件树按父子关系组织控件的树，决定布局嵌套与绘制顺序。
画布设计器中编辑布局的区域；中央浅色“纸面”是最终界面范围。
工程设计器保存的 .csd 文件，包含布局、组件、事件代码和主题。
布局运行时控件树、viewport、theme 等；导出 JSON 的主体。
Viewport布局的画布尺寸、背景和缩放配置。
显式属性直接设置在控件上的属性，优先于主题派生值。
主题项目级的 CSS-like 样式表，由变量、规则、类、变体、媒体/容器条件组成。
规则选择器 + 声明集合。
选择器决定规则匹配哪些控件的表达式，例如 button.primary。
声明规则中的属性键值，例如 background: var(--bg)。
类（class）控件上的标签，供主题类选择器匹配。
变体叠加在基础主题上的命名风格，例如 dark。
媒体条件根据视口宽高/方向/缩放匹配的规则。
容器条件根据最近祖先容器尺寸匹配的规则。
组件可复用的控件模板定义。
组件实例画布上的组件节点，保存自己的 props 与事件绑定。
组件模板组件内部的控件树。
props组件声明的可配置属性；模板用 {{name}} 引用。
幽灵控件设计器为显示组件实例而展开的模板控件；不保存、不参与选择。
事件绑定控件事件到 handler 的映射。
handler事件发生时调用的 C/C++ 函数名。
_comp_组件模板事件前缀，实例层映射到宿主 handler。
资源提供者资源名称到目录的映射，布局用 provider:name/path 引用。
撤销栈保存可撤销编辑操作的历史；支持撤销/重做。
设计器 UI 主题designer_theme.json，只影响设计器自身界面。
