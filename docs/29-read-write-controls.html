35 读写控件数据

35.1 读取控件数据

C++ Binding

C++ Binding 的属性读取返回具体类型；属性名可以使用 PropertyNames.h 常量，也可以直接写字符串。

const std::string caption = saveBtn.GetString(PropertyNames::kCaption);
const bool visible       = saveBtn.GetBool(PropertyNames::kVisible);
const int selected       = saveBtn.GetInt(PropertyNames::kSelectedIndex);
const float fontSize     = saveBtn.GetFloat(PropertyNames::kFontSize);
const std::string anchor = saveBtn.GetEnum(PropertyNames::kAnchor);

UIColor bg = saveBtn.GetColor(PropertyNames::kBackground);
UIStateColor bgStates = saveBtn.GetStateColor(PropertyNames::kBackground);

UIRect r = saveBtn.GetRect();
float l = 0, t = 0, rr = 0, b = 0;
saveBtn.GetContentPadding(l, t, rr, b);
数据方法说明
文本GetString("caption") / GetString("text")Button/Label 用 caption；输入框用 text
整数GetInt("selected-index")索引、枚举数值
浮点GetFloat("font-size")字号、进度、范围
布尔GetBool("visible")可见、启用、勾选
颜色GetColor("background")普通单色
四态颜色GetStateColor("background")normal/hover/pressed/disabled
矩形GetRect()相对父容器的位置和尺寸
内容内边距GetContentPadding(...)content-padding
指针/对象GetPtr("...")行首控件等对象句柄，再用 FromHandle

C ABI

C ABI 的字符串读取需要缓冲区，并通过 outLen 得到完整长度；缓冲区不足时先查询长度再分配。

char caption[256] = {0};
int captionLen = 0;
if (UICornerstone_GetString(inst, saveBtn, "caption",
                            caption, sizeof(caption), &captionLen)) {
    printf("caption=%s len=%d\n", caption, captionLen);
}

int visible = 0;
int selected = -1;
float fontSize = 0.0f;
UICornerstone_GetBool(inst, saveBtn, "visible", &visible);
UICornerstone_GetInt(inst, saveBtn, "selected-index", &selected);
UICornerstone_GetFloat(inst, saveBtn, "font-size", &fontSize);

char anchor[64] = {0};
UICornerstone_GetEnum(inst, saveBtn, "anchor", anchor, sizeof(anchor));

UIColor bg;
UIStateColor bgStates;
if (UICornerstone_GetColor(inst, saveBtn, "background", &bg))
    printf("bg=%02X%02X%02X%02X\n", bg.r, bg.g, bg.b, bg.a);
if (UICornerstone_GetStateColor(inst, saveBtn, "background", &bgStates))
    printf("hover=%02X%02X%02X%02X\n",
           bgStates.hover.r, bgStates.hover.g,
           bgStates.hover.b, bgStates.hover.a);

float x = 0, y = 0, w = 0, h = 0;
float padL = 0, padT = 0, padR = 0, padB = 0;
UICornerstone_GetRect(inst, saveBtn, &x, &y, &w, &h);
UICornerstone_GetContentPadding(inst, saveBtn, &padL, &padT, &padR, &padB);
printf("rect=%.1f,%.1f %.1fx%.1f padding=%.1f,%.1f,%.1f,%.1f\n",
       x, y, w, h, padL, padT, padR, padB);

char type[64] = {0};
UICornerstone_GetControlType(inst, saveBtn, type, sizeof(type));
printf("id=%s type=%s\n", UICornerstone_GetControlId(inst, saveBtn), type);

如果需要读取完整字符串而缓冲区可能不足，先传 out=NULL 查询长度，再按 outLen 分配并读取。

35.2 设置控件数据

C++ Binding

saveBtn.SetString(PropertyNames::kCaption, "保存");
saveBtn.SetBool(PropertyNames::kVisible, true);
saveBtn.SetBool(PropertyNames::kEnabled, false);
saveBtn.SetInt(PropertyNames::kSelectedIndex, 1);
saveBtn.SetFloat(PropertyNames::kFontSize, 18.0f);
saveBtn.SetEnum(PropertyNames::kAnchor, "top-left");

saveBtn.SetColor(PropertyNames::kBackground, UIColor{0x4A, 0x90, 0xD9, 0xFF});
saveBtn.SetStateColor(PropertyNames::kBackground, UIStateColor{
    {0x4A, 0x90, 0xD9, 0xFF},   // normal
    {0x6A, 0xA3, 0xFF, 0xFF},   // hover
    {0x3B, 0x73, 0xD1, 0xFF},   // pressed
    {0x2B, 0x30, 0x38, 0xFF}    // disabled
});

saveBtn.SetRect(24, 16, 160, 40);
saveBtn.SetContentPadding(8, 4, 8, 4);

控件主题类通过 classes 属性设置：

saveBtn.SetString("classes", "primary toolbar");
设置属性会走与设计器属性面板相同的底层通道。若控件有主题规则，显式 Set* 会覆盖主题派生值；需要恢复主题时使用 ClearThemeOverrides。

C ABI

UICornerstone_SetString(inst, saveBtn, "caption", "保存");
UICornerstone_SetBool(inst, saveBtn, "visible", 1);
UICornerstone_SetBool(inst, saveBtn, "enabled", 0);
UICornerstone_SetInt(inst, saveBtn, "selected-index", 1);
UICornerstone_SetFloat(inst, saveBtn, "font-size", 18.0f);
UICornerstone_SetEnum(inst, saveBtn, "anchor", "top-left");

UIColor normal   = { 0x4A, 0x90, 0xD9, 0xFF };
UIColor hover    = { 0x6A, 0xA3, 0xFF, 0xFF };
UIColor pressed  = { 0x3B, 0x73, 0xD1, 0xFF };
UIColor disabled = { 0x2B, 0x30, 0x38, 0xFF };
UIStateColor bgStates = { normal, hover, pressed, disabled };

UICornerstone_SetColor(inst, saveBtn, "background", normal);
UICornerstone_SetStateColor(inst, saveBtn, "background", bgStates);
UICornerstone_SetRect(inst, saveBtn, 24, 16, 160, 40);
UICornerstone_SetContentPadding(inst, saveBtn, 8, 4, 8, 4);
UICornerstone_SetString(inst, saveBtn, "classes", "primary toolbar");

35.3 列表、树和页签的专用接口

C++ Binding

复杂数据不要只靠通用属性。C++ Binding 提供了专用方法，例如：

控件示例
ListViewui->ListViewGetCellText(lv, row, col)、ListViewSetCellText、ListViewGetEditingCell
TreeViewui->TreeViewGetSelectedId(tree)、TreeViewSelectNode、TreeViewBeginEditNode
TabControlctl.SetInt("currentIndex", 1) 或专用页操作方法
ScrollBar / SliderSetFloat("value", ...)、GetFloat("value")，具体键以属性面板为准

完整方法列表见 UICornerstone 的 C++ Binding 头文件与文档。

C ABI 的专用接口

UIControlHandle listView = UICornerstone_FindControl(inst, "userList");
UIControlHandle treeView = UICornerstone_FindControl(inst, "navTree");
UIControlHandle tabCtrl  = UICornerstone_FindControl(inst, "mainTabs");

/* ListView：读取/设置单元格文本 */
char cell[256] = {0};
UICornerstone_ListViewGetCellText(inst, listView, 0, 1, cell, sizeof(cell));
UICornerstone_ListViewSetCellText(inst, listView, 0, 1, "完成");

/* TreeView：读取当前选中节点、选中指定节点 */
char nodeId[128] = {0};
if (UICornerstone_TreeViewGetSelectedId(inst, treeView, nodeId, sizeof(nodeId)))
    printf("selected node=%s\n", nodeId);
UICornerstone_TreeViewSelectNode(inst, treeView, "node-1");
UICornerstone_TreeViewExpandNode(inst, treeView, "node-1");

/* TabControl：切换当前页 */
UICornerstone_SetInt(inst, tabCtrl, "currentIndex", 1);

专用接口的函数名与 C++ Binding 基本一一对应：UICornerstone_ListView...、UICornerstone_TreeView...、UICornerstone_ComboBox...。完整签名见 UICornerstoneAPI.h。

35.4 常用属性名

用途键
文本caption（按钮/标签）、text（输入框/多行文本）
可见/启用visible、enabled
位置/尺寸rect（GetRect/SetRect）
背景/文字/边框background、text-color、border-color
字号font-size
主题类classes
选中索引selected-index
勾选状态checked / check-state（以控件为准）
页签当前页currentIndex（TabControl）
属性键的完整集合见 PropertyNames.h；设计器属性面板显示的字段与这些键对应。不同引擎版本可能增加属性，优先使用常量而不是手写字符串。
