2 设计器概览

CornerstoneDesigner 把 UICornerstone 的 JSON 布局编辑变成一个可视化流程：你不需要手写 JSON，也不需要记住控件属性名。设计器自身也是 UICornerstone 应用（Dogfooding），所以你看到的界面与导出后的界面使用同一套控件体系。

2.1 它能做什么

可视化布局

从工具箱放置控件，在画布上拖动、缩放、对齐和分布。

属性编辑

布局、外观、行为三类属性；支持多选批量编辑。

事件绑定

选择事件类型、生成 handler 名称并导出事件代码。

组件复用

把一组控件做成组件模板，通过 props 生成多个实例。

主题换肤

变量、规则、类、变体、媒体条件；预览与导出一致。

预览与导出

独立窗口预览，导出 JSON、C/C++ 工程和项目报告。

2.2 三种工作状态

状态用途如何进入
设计状态放置控件、编辑属性、查看网格与选中框默认状态
组件编辑编辑组件模板与 props 声明编辑 → 编辑组件…，或双击组件实例
预览状态按最终运行时效果显示当前布局视图 → 预览模式、F5 或画布工具栏“预览”

设计状态中的网格、选中框、控制点和状态预览不会写入工程，也不会出现在导出的运行界面里。

2.3 典型工作流

  1. 新建或打开工程：得到一个可编辑的画布。
  2. 放置控件：从左侧工具箱拖入或双击控件。
  3. 调整布局：拖动位置、拖动控制点改尺寸，使用网格/吸附/对齐。
  4. 编辑属性：在右侧属性面板设置文本、颜色、字体、可见性等。
  5. 绑定事件：在事件页签填写事件与 handler。
  6. 组件化（可选）：把重复结构做成组件。
  7. 主题（可选）：用规则和类统一视觉。
  8. 预览：确认交互与最终效果。
  9. 保存：保存为 .csd 工程，保留设计器元数据。
  10. 导出：导出 JSON 布局或可编译 C/C++ 工程。

2.4 文件类型

文件说明是否包含设计器信息
*.csd设计器工程文件，包含布局、组件、事件代码、主题与元数据是
*.jsonUICornerstone 布局文件，用于导入或导出运行布局否（只保留布局与 theme 等运行时字段）
designer_settings.json设计器自身设置：最近文件、对话框记忆目录仅设计器使用
designer_theme.json设计器自身 UI 主题，与项目主题分离否

2.5 启动前准备

  • 可执行文件旁应有 main_layout.json、assets/、schema/ 和运行库 DLL；开发构建会自动拷贝。
  • 设计器当前使用 SDL3 后端；请确认 UICornerstone.dll、UIBackend_sdl3.dll 与 SDL3 运行库同批、同目录。
  • 从源码构建请参考 design/guidelines/build.md；构建输出在 build/sdl3/Debug 或 build/sdl3/Release。
  • 首次启动没有工程时显示空白画布，可直接新建工程。

2.6 与设计文档的关系

  • 本手册：面向操作，告诉你每一步点哪里、看到什么、失败时先检查什么。
  • design/：面向实现，解释需求、数据结构、模块边界和关键决策。
  • UICornerstone 文档：说明控件属性、事件和主题语法的底层语义；本手册只讲设计器中的用法。
