13 基础与输入控件

本章把工具箱中的基础控件和常用的输入类高级控件放在一起介绍。它们大多只需要“文本/值 + 事件”两类配置，适合先完成界面骨架，再逐步补主题和校验逻辑。

13.1 按钮 Button

项目说明
典型用途提交、确认、打开弹窗、执行动作
常用属性文本、字体、字号、文字色、背景色、圆角、边框
常用事件点击事件（在事件页签选择实际列表项）
注意按钮文字过长时先调整尺寸或字号；不要把业务状态只放在颜色上，需同时修改文本

绑定点击事件后，handler 在点击触发时执行。需要根据按钮来源区分多个按钮时，可在代码中读取控件的 ID 或为每个按钮使用独立 handler。

13.2 标签 Label

项目说明
典型用途标题、说明文字、只读数据显示
常用属性文本、字体、字号、对齐、颜色、是否可点击
事件只有启用可点击行为时才需要点击事件
注意Label 不是输入控件；需要用户修改内容时使用 EditBox 或 TextArea

13.3 复选框 CheckBox

  • 文本说明选项含义，勾选状态表示布尔值。
  • 在属性面板设置初始勾选状态；运行时可通过事件或代码读取/修改。
  • 需要“一组只能选一个”时改用单选按钮或 ComboBox，不要用多个 CheckBox 模拟。
  • 常用事件：勾选状态变化；实际事件名以事件页签为准。

13.4 输入框 EditBox

项目说明
典型用途单行文本、名称、路径、搜索关键词
常用属性文本、placeholder、字体/字号、只读、密码模式、最大长度（如 schema 提供）
常用事件文本变化、回车确认、失焦提交
注意placeholder 不是默认值；需要初始文本时填写“文本”属性

输入类控件要配合 Tab 焦点顺序使用。设计器中可以直接在属性面板修改文本；运行时是否提交由宿主事件逻辑决定。

13.5 多行文本 TextArea

  • 用于备注、日志、配置等长文本输入。
  • 属性面板设置初始文本、字体和滚动相关字段；运行时由用户输入。
  • 需要严格行数/字数限制时，在事件 handler 或运行时逻辑中校验，不要只依赖控件外观。
  • TextArea 与 EditBox 的事件不同，绑定前先确认事件页签列表。

13.6 数字框 NumericUpDown

项目说明
典型用途数量、比例、坐标、阈值等数值输入
常用属性最小值、最大值、步长、小数位、当前值、只读
常用事件值变化；需要“输入完成后提交”时用失焦/回车事件（以控件事件列表为准）
注意范围和步长要在设计期设好，运行时再改会增加状态同步成本

13.7 取色器 ColorPicker

  • 用于让用户选择颜色，常用于主题编辑、绘图和样式配置界面。
  • 属性面板可设置初始颜色；运行时通过颜色变化事件读取新值。
  • 颜色统一使用 #RRGGBBAA 或设计器提供的 RGBA 控件；导出到代码时注意颜色类型转换。
  • 取色器弹出面板的尺寸/定位由控件内部处理；给它留出足够的父容器空间。

13.8 进度条 ProgressBar

  • 显示任务进度，通常只读；不要把它当作 Slider 使用。
  • 常用字段：当前值、最小值/最大值、方向、填充色。
  • 进度变化由代码或外部事件驱动；设计期可设置一个示例值查看外观。

13.9 滑块 Slider

  • 用于在连续范围内选择数值，例如音量、缩放、透明度。
  • 常用字段：最小值、最大值、当前值、步长、方向。
  • 滑动事件的触发频率可能很高；handler 中避免做重资源加载或同步导出。

13.10 滚动条 ScrollBar

  • 通常作为滚动容器或自定义滚动区域的组成部分，不建议单独用来表达数值。
  • 配置方向、范围、页面步长和当前值；与可滚动内容联动时需要宿主逻辑。
  • 如果只是滚动 ListView/TextArea，优先使用控件自带的滚动条，不要重复叠加。

13.11 输入控件共同问题

现象检查
运行时无法输入控件是否启用、是否只读、是否被上层透明控件遮挡
文字被裁切控件高度、字号、内边距和字体是否匹配
点击不触发是否绑定到了错误的事件；父容器是否拦截了事件
主题后颜色不对显式属性与项目主题的覆盖关系，见 主题系统
