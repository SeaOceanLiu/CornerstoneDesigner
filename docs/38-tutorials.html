38 实战教程

下面的教程把前面的功能串起来。建议按顺序做一遍，遇到不熟悉的字段再回查对应章节。

38.1 教程 A：登录表单

目标：做一个包含标题、用户名、密码和登录按钮的界面。

  1. 新建工程，画布选择 1280×800。
  2. 放置一个 Panel 作为卡片，调整到画布中央，设置背景色和圆角。
  3. 在 Panel 内放置 Label 作为标题，文本设为“登录”。
  4. 放置两个 EditBox，分别作为用户名和密码输入框；在属性面板设置文本占位/内容。
  5. 放置 Button，文本设为“登录”。
  6. 多选标题、输入框和按钮，使用“水平居中”对齐。
  7. 选中按钮，事件页签添加点击事件，handler 命名为 onLoginClick。
  8. 预览，确认布局；保存工程。
输入框和按钮的宽度可以用“等宽”对齐，再用“水平分布”调整垂直间距。

38.2 教程 B：列表与资源

目标：使用 ListView 展示数据，并引用一张图片资源。

  1. 新建工程，放置 ListView。
  2. 在属性/行为中配置列或行数据；如果使用资源，先在资源页签插入 provider。
  3. 放置 Image，把图片属性设置为 provider:名称/图片.png。
  4. 在事件页签给 ListView 绑定选择/点击事件。
  5. 预览，确认列表和图片都能显示。
  6. 导出 JSON，检查 layout 中保留了 provider 映射。

38.3 教程 C：组件复用

目标：做一个按钮组件，通过 props 改变文本和颜色。

  1. 放置一个 Button，设置基本样式。
  2. 选中按钮，编辑 → 由选中控件创建组件…，命名为 ActionButton。
  3. 进入组件编辑，打开“组件属性…”，声明：
{
  "label": { "type": "string", "default": "操作" },
  "bg": { "type": "string", "default": "#4A90D9FF" }
}
  1. 在模板按钮的文本中使用 {{label}}，背景色使用 {{bg}}。
  2. 返回画布，从工具箱“组件”分组拖入两个实例。
  3. 分别修改实例的 label/bg，画布应显示不同文本和颜色。
  4. 给实例绑定事件，检查事件面板的 _comp_ 键。

38.4 教程 D：主题换肤

目标：用变量和类给按钮换主色，并添加悬停状态。

  1. 打开主题管理器，点击“变量…”，添加 --primary = #4A90D9FF。
  2. 新增规则：选择器 button.primary，背景色填 var(--primary)，文字色白色，圆角 6。
  3. 新增规则：选择器 button.primary:hover，背景色改为更亮的蓝色。
  4. 在画布选中按钮，类名填 primary，点击“类应用到选中”。
  5. 预览，悬停按钮查看颜色变化。
  6. 新增变体 dark，在变体作用域中覆盖背景色，再预览切换效果。
  7. 新增媒体条件，在窄窗口下调整字号或内边距。
主题规则不要和控件显式颜色打架。若按钮已在属性面板显式设色，主题不会覆盖它；请清除显式颜色或改用主题统一管理。

38.5 教程 E：导出并运行 C++ 工程

  1. 完成布局和事件绑定，预览通过。
  2. 保存 .csd。
  3. 选择 文件 → 导出为可编译C++项目，选择空目录。
  4. 打开导出目录的 README.md，按说明配置构建。
  5. 修改 events.c 中生成的 handler 函数体，加入业务逻辑。
  6. 编译运行，确认界面和事件与设计器预览一致。

38.6 教程检查表

检查项通过标准
布局控件位置、尺寸、层级符合设计
属性文本、颜色、可见/启用状态正确
事件绑定存在、handler 合法、导出代码有实现
组件实例 props 生效，模板修改可复用
主题预览中规则生效，显式覆盖符合预期
导出工程可编译，运行时与预览一致
