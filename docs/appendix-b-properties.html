附录 B 属性速查

属性面板由 UICornerstone schema 驱动；本附录只列常用项，完整字段以属性面板、原始 JSON 与 schema 为准。

B.1 通用布局

键类型说明
idstring控件 ID，供事件/代码引用
rectobject{x,y,w,h}，相对父容器
anchorstring锚点，例如 top-left、top-stretch、fill
visiblebool是否显示并参与命中
enabledbool是否响应交互
always-on-topbool是否置顶绘制
flow-weightnumber在流式布局中的伸缩权重

B.2 通用外观

键类型说明
colors.backgroundstate color背景色，可含 normal/hover/pressed/disabled
colors.textstate color文字色
colors.borderstate color边框色
border-visiblebool是否显示边框
border-radiusnumber圆角
fontobject字体名/字号等
font-sizenumber字号
text-shadowcolor文字阴影颜色
box-shadowobject盒阴影
content-paddingobject/number内容内边距（不影响外框）
classesstring/array主题类名
theme-eligiblebool是否参与主题匹配；内部辅助控件默认 false

B.3 文本/输入类

键适用说明
captionButton/Label/CheckBox 等显示文本
textEditBox/TextArea输入内容
placeholderEditBox占位提示（如支持）
selected-indexComboBox/ListView 等当前选中项
check-stateCheckBoxchecked/unchecked/indeterminate
word-wrapTextArea/Label自动换行

B.4 列表/树

键说明
itemsComboBox 等候选数据
columnsListView 列定义
rowsListView 行数据
header-background表头背景色（主题也可设置）
reorderable是否允许拖拽重排
draggable / droppable拖拽框架旗标

B.5 交互与拖拽

键说明
draggable控件可作为拖动源
droppable控件可接收拖放
drag-threshold起拖阈值
reorderable列表/树/页签内置重排
events事件绑定对象，键为事件名，值为 handler

B.6 组件实例

键说明
type组件名（模板类型）
props实例属性值，对应模板的 {{prop}}
events实例侧 _comp_ 事件映射

B.7 画布（Bench）

键说明
viewport.width / height设计画布尺寸
viewport.id画布 ID，例如 canvas
viewport.background预览/运行背景色
title窗口标题（如支持）
颜色推荐统一使用 #RRGGBBAA；数值属性可以写数字，也可以写数字字符串。具体解析以 UICornerstone 当前版本为准。
