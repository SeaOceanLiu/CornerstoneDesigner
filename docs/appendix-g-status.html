G.2 明确限制

编辑菜单预留项

当前版本以下菜单项是预留入口，尚未实现实际行为：

  • 编辑 → 复制
  • 编辑 → 粘贴
  • 编辑 → 置前
  • 编辑 → 置后
  • 编辑 → 上移 / 下移（请使用控件树右键上移/下移）

删除请用 Delete 或编辑 → 删除；层级调整请使用控件树右键菜单。

主题显示范围

  • 设计画布主要显示显式样式和设计态，项目主题的完整效果以预览/导出为准。
  • 可视化主题管理器覆盖常用字段；复杂选择器、变体内的媒体/容器结构请使用“主题 JSON…”。
  • 主题规则不改变控件矩形；padding 影响内容区，不影响外框尺寸。

自动保存

当前版本没有自动保存恢复流程。请主动保存 .csd，不要在关闭前只保留内存修改。

其他

  • 设计器当前以 SDL3 后端为验证目标。
  • 部分控件（Dialog/Popup/HandleControl 等）主要用于运行时或辅助用途，设计态可能只显示占位。
  • 颜色状态规则中 :selected 近似使用 pressed 通道。
  • 不支持 CSS 后代/子选择器、属性选择器、逗号分组、!important 和 opacity。

G.3 状态标记含义

标记含义
可用常规操作可使用，已有预览/导出路径
部分基础能力可用，但高级场景需要 JSON 或存在限制
未实现界面可能有入口，但当前版本没有实际行为
如果你依赖某个限制项完成工作，请把使用场景和最小复现工程反馈给维护者；手册会在功能落地后同步更新。
