附录 D 主题语法参考

项目主题是 CSS-like 对象。本附录给出设计器当前支持的主要语法；完整实现以 UICornerstone 当前版本为准。

D.1 顶层结构

{
  "variables": {},
  "styles": [],
  "variants": {},
  "media": [],
  "containerQueries": [],
  "fonts": {},
  "colors": {}
}
  • fonts / colors 是旧主题语法，仍兼容。
  • 新规则与旧主题可同时存在；显式属性始终优先。
  • styles 是基础规则；variants、media、containerQueries 按层序叠加。

D.2 规则

{
  "selector": "button.primary:hover",
  "declarations": {
    "background": "var(--accent)",
    "text-color": "#FFFFFFFF",
    "border-radius": 8
  }
}

V1 不支持后代/子选择器、属性选择器、逗号分组和 !important。复杂选择器请拆成多条规则。

D.3 选择器

形式示例
类型button、label、panel
类.primary、button.primary
ID#saveBtn
复合button.primary#saveBtn
状态button.primary:hover
通配*

状态支持 :hover、:pressed、:disabled、:selected。:selected 当前近似 pressed 通道。

D.4 声明

声明值说明
background颜色背景色
text-color颜色文字色
border-color颜色边框色
text-shadow颜色文字阴影
shadow-offset-x / shadow-offset-y数值文字阴影偏移
font-family字体名字体
font-size数值字号
font-stylenormal/bold/italic/underline/strikethrough字体样式
border-radius数值圆角
padding数字 / “v h” / “t r b l”内容内边距
content-padding对象/字符串通用内容内边距
box-shadow对象盒阴影
控件专有键颜色/数值/字符串落到控件属性通道

D.5 颜色和值

  • #RRGGBB、#RRGGBBAA。
  • rgb(r,g,b)、rgba(r,g,b,a)。
  • 常用颜色名。
  • 数值可写数字或数字字符串。
  • var(--name) 引用变量，支持多级引用。

D.6 变量

"variables": {
  "--bg": "#10141C",
  "--accent": "#2D7FF9",
  "--text": "#F5F8FF"
}

规则示例："background": "var(--bg)"。未知变量回退；循环引用停止解析。

D.7 变体

"variants": {
  "dark": {
    "variables": { "--bg": "#0B0F16" },
    "styles": [
      { "selector": "panel.root", "declarations": { "background": "var(--bg)" } }
    ]
  }
}

层序：基础普通 → 基础媒体 → 基础容器 → 变体普通 → 变体媒体 → 变体容器。

D.8 媒体条件

"media": [
  {
    "id": "compact",
    "query": "(max-width: 800px)",
    "variables": { "--gap": 8 },
    "styles": [
      { "selector": "button", "declarations": { "padding": "4 8" } }
    ]
  }
]

查询可以写字符串或对象，例如 {"max-width": 800, "orientation": "portrait"}。支持 min/max width/height、orientation 和缩放范围。

D.9 容器条件

"containerQueries": [
  {
    "id": "narrow",
    "container": "panel.sidebar",
    "query": "(max-width: 280px)",
    "styles": []
  }
]

container 是简单祖先选择器；匹配最近祖先的 contentRect。容器查询层序在媒体之后、变体之前。

D.10 优先级

  1. 显式属性（JSON/属性面板/公开 Set*）。
  2. ID 选择器。
  3. 类选择器。
  4. 类型选择器。
  5. 同权重按规则顺序，后者覆盖。
  6. 状态规则优先于同选择器的无状态规则。

D.11 示例主题

{
  "variables": {
    "--bg": "#10141C", "--card": "#1A2130",
    "--line": "#2B3648", "--text": "#F5F8FF", "--accent": "#2D7FF9"
  },
  "styles": [
    { "selector": "panel.root", "declarations": { "background": "var(--bg)" } },
    { "selector": "panel.card", "declarations": {
        "background": "var(--card)", "border-color": "var(--line)",
        "border-radius": 14 } },
    { "selector": "button.primary", "declarations": {
        "background": "var(--accent)", "text-color": "#FFFFFFFF",
        "padding": "8 16", "border-radius": 8 } },
    { "selector": "button.primary:hover", "declarations": {
        "background": "#4A90D9" } }
  ]
}
