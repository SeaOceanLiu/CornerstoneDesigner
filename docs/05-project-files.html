6 工程与文件

6.1 新建工程

选择 文件 → 新建。设计器会清空画布、组件定义、事件代码和主题，恢复默认画布尺寸，并清除当前工程路径。

新建前如果有未保存修改，请先保存。当前版本不会自动提示保存。

6.2 打开工程

选择 文件 → 打开，在文件对话框中选择 .csd 工程。也可以：

  • 把 .csd 或 .json 文件从资源管理器拖入设计器窗口。
  • 从 文件 → 最近文件 选择最近工程。
  • 启动时通过命令行把文件路径作为参数传入。

打开成功后，窗口标题显示项目文件名，状态栏提示“已打开”；失败时保留当前工程并在状态栏或控制台给出错误。

6.3 保存与另存为

操作菜单位置说明
保存文件 → 保存已有路径直接保存；无路径时弹出保存对话框
另存为文件 → 另存为选择新路径，不影响原文件

保存成功后未保存标记 * 消失；保存失败时先检查目标目录是否存在、文件是否被占用、路径是否过长。

6.4 最近文件

文件 → 最近文件 最多保留 10 个项目，最近使用的排在最前。列表会压缩显示超长路径，但点击时仍使用完整路径。

  • 不存在的路径会在启动或打开时从列表中移除。
  • 最近文件保存在设计器 exe 同目录的 designer_settings.json。
  • 列表为空时“最近文件”菜单项置灰。

6.5 导入和导出 JSON

操作菜单结果
导入 JSON文件 → 导入 JSON用 JSON 布局替换当前画布内容，成为设计器中的工程
导出 JSON文件 → 导出 JSON只导出运行布局，供 UICornerstone 加载

.csd 与导出 .json 的区别：.csd 还包含设计器元数据（组件、事件代码、配置等）；导出 JSON 主要是控件树、viewport 和运行时字段。

导入和导出走的是不同路径：导入用于接续编辑别人的布局；导出用于把当前工程交给运行时。需要保留设计器信息时不要用导出 JSON 代替保存。

6.6 拖入文件

  • 拖入 .csd：作为工程打开。
  • 拖入 .json：作为布局导入。
  • 其它扩展名：忽略，不改变当前工程。

6.7 命令行打开

可以把路径作为启动参数：

CornerstoneDesigner.exe "D:\Projects\Demo.csd"

命令行路径不经过文件对话框，适合长路径或从脚本启动设计器。路径无效时启动普通空白工程。

6.8 设计器设置

designer_settings.json 位于 exe 同目录，当前记录：

  • lastFileDir：文件对话框记忆目录
  • lastFolderDir：目录对话框记忆目录
  • recentFiles：最近文件列表

文件损坏或缺失时设计器使用空设置启动，不会阻止打开工程。

6.9 工程文件里有什么

字段内容
layout.controls控件树、位置、尺寸、属性、事件
layout.components组件定义与模板
layout.viewport画布尺寸、标题、背景
layout.theme项目主题（可选）
metadata事件代码、handler includes、画布元数据
version工程格式版本
